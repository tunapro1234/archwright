# Assets

Every visual and every sound in Archwright is generated in code at runtime: stone and wood meshes, the atelier room and desk, their grain, chisel-mark and plank
textures in `src/scene/models.ts` (colours in `src/scene/palette.ts`), the stone notes, the held arch's chord, the centering's creak and the collapse with the Web Audio API in `src/audio/synth.ts` (from the data in `src/audio/music.ts`; no recordings). The build
contains no third-party model, texture, font or sound file, and the page loads nothing from another origin.
