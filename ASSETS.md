# Assets

Every visual and every sound in Archwright is generated in code at runtime: stone and wood meshes, their grain, chisel-mark and plank
textures in `src/scene/models.ts` (colours in `src/scene/palette.ts`), the click, scrape, hold and collapse sounds with the Web Audio API in `src/audio/synth.ts`. The build
contains no third-party model, texture, font or sound file, and the page loads nothing from another origin.
