# Assets

Every visual and every sound in Archwright is generated in code at runtime: stone and wood meshes and their noise textures in
`src/scene/meshes.ts`, the click, scrape, hold and collapse sounds with the Web Audio API in `src/audio/synth.ts`. The build
contains no third-party model, texture, font or sound file, and the page loads nothing from another origin.
